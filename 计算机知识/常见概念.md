8.API（application programming interface）应用程序编程接口：软件之间通信和共享数据的桥梁，它定义了一套规则和协议，让不同的应用或系统能够以标准化的方式交换信息。客户端（你操作软件）和服务器或系统中间的桥梁，形式上是一段有格式的请求，分为Rest api和Graph QL，日常大部分都是rest：每个资源对应的是URL，APIkey：类似身份证，记录你的信息。

9.MCP（model context protocol）模型上下文协议：模型和外部世界的一个通信协议，让模型能调外部资源（包括数据库，API，第三方的Saa S），工具，工作路径：prompt>mcp client（客户端：桌面助手，bot，agent）>mcp server（能力适配器，负责和外部通信）>resource tools
10.http：网页和服务器的一个通信协议
11.URL：互联网上用于标识和定位资源的标准地理格式，俗称“网址”
12.JASON（java script object notation）：一种轻量级的数据交换格式，广泛应用于api通信和配置文件
13.Docker：一个开源的应用容器引擎（装有代码，系统工具，配置文件等），建构一个在不同环境中行为一致的应用。
14.shell:操作系统中用户与内核之间的接口程序，将命令解释给计算机操作系统。
15.绝对路径（abusolute path）：从文件系统的根目录开始，包含到达目标文件所需的所有目录层级的完整路径。windows一般这么写：C:\Users\Documents\test.txt（Windows用反斜杠）
而Mac或Linus 一般这么写：/home/user/Documents/test.txt（正斜杠）
相对路径（relative path）：相对于当前工作目录的路径。写法举例：..退回上一级
Windows：..\User\documents(先退再进，此时和原来的在同一目录下，然后再进）
Mac/Linus：../User/documents（同理）
注意：..\user会先返回上级目录，然后直接在上级目录里建一个文件，而.\user才会直接在同级目录下建一个文件

# 概念
- 仓库的根目录：总文件夹的下一级
- 链接深表示该笔记已创建，链接浅表示该笔记未创建
- .obsidian文件夹是它的配置文件夹，里面的文件存放了关于obsidisn的配置
- workspace记录的是你上次关闭软件时的界面状态，例如你最后打开了哪几个笔记之类的，这些对别人毫无意义还可能会导致不同设备间的配置冲突，不放到ignore里的话会给你记一大堆垃圾数据，需要在根目录下的.gitignore里加上两行
     - .obsidian/workspace.json（不记录桌面端（电脑）的数据）
     - .obsidian/workspace-mobile.json（不记录移动端（手机平板）的数据）
- 在“文件与链接”里可以改变新建笔记的存放位置和附件（如图片）的存放位置
- 电脑右下角有笔记的字数显示，平板往左滑右边出来的一栏东西的下方显示字数
# 技巧
- 1.-+空格：分点，敲完回车自动第二个点，tab退格键，变成二级分点
- 2.前后各两个*或control+B加粗文字
- 3.可以在代码块里批注：三个、（记得是英文版的）
- 4.链接文件：两个中括号中间放文件（笔记）（没有的话会自己创建）
- 5.引入网页链接：contral+k，前面是网页名字，后面是网页地址
- 6.打标签：#标签，通过打标签可以给文件建立属性（颜色），建立属性后可以很好的分类
- 7.找到笔记连接的页面：右上角出链反链
- 8.在文件夹里建立一个和文件夹名一样的文件方便管理
- 9.n个#+空格+文字：n级标题
- 10.关闭代码折叠功能：obsidian的设计者规定要用这个名字
     1.在.obsidian里创建名为snippets的文件夹（，不然找不到）
     2.在文件夹里创建一个纯文本文件
     3.复制以下代码进去：.markdown-source-view.mod-cm6 .cm-fold-indicator { display: none !important; }
     4.保存然后将后缀名改为.css（Cascading Style Sheets，层叠样式表，能控制视觉元素包括文字与颜色，空间与尺寸，位置与布局，动态与动画......)
     5.在obsidian的设置的外观的css样式代码片段里找到这个文件并打开



# 插件
- 1.日记（daily note）：每天生成规定模板的日记，每天进行复盘
- 2.在模板里选择文件夹，该文件夹里的笔记就是模板库了
- 3.可以在左边保存工作区布局
- 4.画板工具：画思维导图
- 5.contral+m打开mind map插件

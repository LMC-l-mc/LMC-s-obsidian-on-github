# 第二课：
F12（以谷歌为例）
- Elements：包含运行完JavaScript脚本（显示页面状态，包含所有从服务器请求的数据） 后的最终结果，而原始的页面源代码只有一个框架（低端的有数据）
	- 操作：点击左上角（select an element in the page to inspect it)就可以修改页面显示的内容结构了
- Console:操作台，可以在里面写JavaScript代码调试页面
- Source：整个页面的所有资源，包括页面源代码，脚本，图片……
- Network：访问网站的所有网络请求都会在这里体现(Fetch/XHR里放的是数据)
- 勾上“keep log”可以保留之前的所有网络请求
- 点“禁用”符号（clear network log)可以清除之前所有的网络请求

# 第三课：HTTP请求
## 请求：
- 在Network的文件名的Headers里
1.请求行（General）：
- 请求方式：爬虫一般是get/post
- 请求url地址
- 协议：
2.请求头（Request headers):放服务器要使用的附加信息，重要内容有：
- User-Agent:请求载体的身份识别
- Referer：防盗链（用来反爬)
- cookie:本地字符串数据信息（用户登录信息，反爬的token）
3.空行：起分割作用
4.请求体：放请求参数

## 响应：
1.状态行：协议（和请求的对应），状态码（200是没问题，302，404urlnofound，500服务器错了）

# 第一课：
```
from urllib.request import urlopen  
#从urllib文件夹里的request文件引入urlopen函数  
#模块：一个python文件就是一个模块  
url="http://www.baidu.com"  
resp=urlopen(url)  
#print(resp.read().decode("utf-8"))、  
with open("C:/爬虫练习/第一课练习.html","w",encoding="utf-8") as f:  
   f.write(resp.read().decode("utf-8"))
#然后对应的文件里就会出现百度网页对应的源代码
```
